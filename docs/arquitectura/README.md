# Arquitectura de CliniTENS

Abrir [clinitens.html](clinitens.html) directamente en Google Chrome; no requiere servidor Django. El visor incluye búsqueda, enfoque de nodos, zoom, tema y exportación.

- [candidate.json](candidate.json): especificación Archify vigente.
- [FUENTES.md](FUENTES.md) y [fuentes.sha256.json](fuentes.sha256.json): trazabilidad manual a los archivos locales.
- [validation.md](validation.md): comandos, resultados y límites.
- [Recibo final](review-2/clinitens.finalize-summary.json) y [pruebas Chrome](review-2/clinitens.browser-check.json).
- spec.md, plan.md, tasks.md: alcance, plan y estado documental.

El diagrama contiene componentes actuales; notas ámbar separan lo planificado. La copia no tiene Git: no hay fuentes verificadas contra un commit. Los recibos de raíz y candidate.primera-version.json son históricos del primer intento aprobado; consultar review-2 para el HTML vigente.
